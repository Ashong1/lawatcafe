4. Safety fixes found in code review

  • Archived accounts still received shortage, stock and network emails — now only active accounts.
  • Any device could fake its address to dodge the wrong-code and sign-in limits — only the shop's proxy is trusted.
  • Restoring the oldest backup deleted it first — the backup being restored is never pruned.
  • The AI Usage card ignored a saved key and stalled offline — fixed.
  • The Sales page counted voided orders in its totals — fixed.
  • Profile allowed staff to delete their own account — removed.

5. Answered during the evaluation

  • Server security on guest Wi-Fi: firewall rules give guests internet only; SSH and admin pages of the server, firewall and DNS are blocked for them.
  • HTTPS, offline use, AI token limits, scheduled jobs, BIR receipts, Senior/PWD discounts, reprinting: already in place.
